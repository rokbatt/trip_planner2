# 상업화 준비 체크리스트

진행 상황을 세션이 바뀌어도 이어 가려고 만든 문서예요. 칸을 채울 때마다 이 파일을 함께 고쳐요.
표시: `[x]` 완료 · `[ ]` 할 일 · 👤 사용자가 할 일(콘솔·계약·신고·결정) · 🤖 Claude가 PR로 할 일
구분: **확인** = 코드·콘솔로 직접 본 것 · **추정** = 아직 확인 안 한 것(확인 방법을 같이 적음)

원칙
- 가격·요금제·랜딩 문구는 사용자가 정해요. Claude는 원가에 근거한 후보만 내요.
- 운영 데이터 삭제, DB 스키마 변경, 키 교체·폐기, 외부 콘솔 설정, 결제·요금 변경은 사용자 확인 뒤에 해요.
  SQL은 파일로 만들고 실행은 사용자가 Supabase 대시보드에서 해요.
- 법률 항목은 일반적인 요건을 정리한 것이에요. 최종 판단은 관할 기관(세무서·구청·방송통신위원회) 안내나 전문가 확인으로 해요.

> **유료화 보류 · 무료 운영(사용자 결정 2026-11-24).** 건강보험 피부양자 영향 때문에 사업자등록을 하지 않는다. 결제 코드는 완성·닫힘.
> 3단계 A(사업자)·D(PG)·E(출시)는 보류. 사용자 할 일 총정리는 `docs/LAUNCH_HANDOFF.md` 2장.

### A. 사업자 — 👤 ⏸ **보류**(피부양자 영향, 11-24) — 유료화를 다시 정할 때 세무사·공단 확인 뒤

- [ ] 👤 **과세 유형 정하기** — 간이과세자 / 일반과세자.
  - 연매출이 작으면 보통 간이과세를 신청할 수 있고, 간이과세자는 통신판매업 신고 면제 사유이기도 해요.
  - 다만 업종이나 상황에 따라 다를 수 있어서 **홈택스 상담이나 세무서에서 확인**해요.
- [ ] 👤 **업종 정하기** — 온라인으로 디지털 서비스(이용권)를 파는 업종이에요.
  - 업종코드는 세무서·홈택스에서 "웹 서비스 이용권 판매"라고 설명하고 안내받아요.
  - 코드를 추측해서 적지 않아요.
- [ ] 👤 **사업장 주소 정하기** — 자택도 가능해요.
  - 단, 이 주소는 **사이트 아래 사업자 정보와 통신판매업 정보에 공개**돼요.
  - 공개가 싫으면 비상주 사무실 같은 방법을 검토해요.
- [ ] 👤 **사업자등록 신청** — 홈택스 온라인 또는 관할 세무서.
  - 청년 창업 세액 감면 같은 혜택이 있는지도 같이 물어봐요(해당 여부는 확인 필요).

- [ ] 👤 **통신판매업 신고** — 정부24 또는 관할 시·군·구청.

  - 신고가 받아들여지면 등록면허세가 부과돼요.
