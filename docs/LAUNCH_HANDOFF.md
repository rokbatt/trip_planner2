# 서비스 개시 · 유료 결제 인계 문서

새 채팅에서 "유료 결제·서비스 개시" 작업을 이어 가기 위한 문서예요. **새 세션은 `Claude.md` → 이 문서 → `docs/COMMERCIAL_READINESS.md` 순서로 읽고 시작해요.**
마지막 갱신: 2026-11-24 (결제 개발 C-1~C-7 완료 — 남은 것은 사업자등록·포트원 계약·출시 점검)

## 0. 일하는 방식 (사용자와 정한 규칙 — 그대로 지킨다)

- 역할: 몽실이(Mongsil) 상업화·운영 담당. 말투는 해요체, 짧고 분명하게("~한다" 금지)
- 보고 형식: **요약 3줄 / 발견 사항 표 / 고친 것(PR 링크) / 사용자가 할 일 / 다음 점검**
- **비밀값은 채팅·코드·커밋·PR에 절대 쓰지 않는다.** 필요하면 "어떤 값이 어디 필요한지"만 말한다. service_role 키는 Claude에게 주지 않는다
- **먼저 확인받을 것**: 운영 데이터 삭제, DB 스키마 변경, 키 교체·폐기, 외부 콘솔 설정, 결제·요금 관련 변경
- SQL은 `supabase/*.sql` 파일로 만들고 **실행은 사용자가 Supabase 대시보드에서** 한다(한 줄에 한 구문, 주석에 세미콜론·달러 기호 금지)
- 코드 수정: 브랜치(`claude/gallant-brown-212cfs`) → PR → CI "타입체크 · 빌드" 통과 → 병합. **한 PR에 한 주제**
  - "Workers Builds: mongsil" 검사는 PR마다 실패한다(`wrangler preview`가 `previews` 설정 요구) — 알려진 문제, 병합 판단에 쓰지 않는다. 실패 시 PR에 한 번 설명 댓글
- 추측으로 단정하지 않는다 — **확인한 것과 추정한 것을 나눠 적는다**
- **랜딩 문구·가격은 사용자가 정하기 전엔 바꾸지 않는다.** Claude는 원가 근거 후보만 낸다
- 정기 실행(예약 작업)은 제안만 하고, 만들기 전에 묻는다
- 파일은 GitHub 링크로 전달한다(클라우드 세션은 쉬면 꺼져서 로컬 파일이 안 열린다)

## 4. 결제 설계 (확정안, 2026-11-24)

**`docs/PAYMENT_DESIGN.md`가 기준이에요.** 요점:
- 포트원 V2: 결제창(브라우저 SDK) → Worker `/api/pay/complete`가 포트원에 다시 조회해서 상태·금액·상점을 확인 → DB 함수 `grant_pro_pass`로 한 번만 반영. 웹훅(Standard Webhooks 서명)이 누락을 메움
- 결제 주소는 `api/`가 아니라 Worker 안(`worker/pay.ts`, 12개 한도)
- `payments`는 탈퇴해도 남김(5년 보관, `user_id`만 비움) · `user_plans.web_left`로 이용권당 웹 검색 100번
- 환불은 수동(메일 요청 → 관리자 주소 → 포트원 취소 → `revoke_pro_pass`)
- 남은 확인: 환불의 "사용" 기준을 PRO 전용 기능 3개로 넓힐지, 결제자 이메일 5년 보관, 포트원 테스트 계정
